CASE STUDY // FINTECH PLATFORM

Spendly — AI Personal Finance Platform

A modern personal finance platform providing automated expense categorization, real-time budgeting, and AI-driven financial insights.

GitHub Repository Live Demo

1. Why I Built This

Traditional personal expense trackers are manual, tedious, and fail to provide predictive insights into personal budgeting. I built Spendly to create an effortless FinTech experience powered by real-time analytics, automated budget allocation, and actionable AI recommendations tailored to individual spending habits.

2. Problem Statement & Engineering Solution

Users struggle to maintain financial discipline due to fragmented banking apps and manual logging. Spendly solves this by combining a high-performance React SPA with Firebase Firestore real-time data sync and a FastAPI backend service that runs intelligent LLM expense recommendations.

3. Categorized Technology Stack

Frontend: React, Custom CSS Design Tokens, Charting Systems
Backend: FastAPI, Python Microservices
Database & Auth: Firebase Authentication, Firestore
AI Engine: OpenRouter API, Custom Financial Prompt Pipelines

4. Engineering Challenges & Trade-offs

Optimizing data aggregation across historical transactions without introducing client UI latency required implementing Firestore indexing and client-side memory caching, achieving sub-100ms render speeds for complex analytics charts.

CASE STUDY // CYBERSECURITY PLATFORM

Sentinel AI — Cyber Threat Intelligence (CTI) Platform

India's AI-Powered CTI Platform automating OSINT domain recon, Indicator of Compromise (IOC) management, and explainable threat scoring.

GitHub Repository

1. Why I Built This

Security Operations Centers (SOCs) are overwhelmed by disjointed threat feeds and raw IOC logs. Sentinel AI was engineered to centralize threat intelligence, automate OSINT recon (VirusTotal, WHOIS, Google Safe Browsing), and present explainable AI threat diagnostics for rapid incident triage.

2. System Architecture & Telemetry Pipeline

Sentinel AI operates an asynchronous threat scanning pipeline built in Python & FastAPI. Incoming indicators pass through multiple recon modules (WHOIS, reputation APIs, typosquatting scanners) before entering an Explainable AI correlation engine that computes threat verdict scores.

3. Categorized Technology Stack

Languages: Python, C / C++ Modules
APIs & Security: VirusTotal API, WHOIS, Safe Browsing, OSINT Recon
Backend: FastAPI Asynchronous Worker Pipeline
Environment: Linux / CTI Security Console

4. Engineering Challenges & Trade-offs

Handling API rate limits across external threat intelligence providers required designing a resilient asynchronous task queue with exponential backoff, ensuring 100% telemetry availability during threat spikes.

CASE STUDY // ENTERPRISE AGENTIC AI

SupportFlow AI — Enterprise Agentic AI Platform

Multi-agent orchestration platform executing stateful workflows, persistent memory, and dynamic tool calling via LangGraph and Ollama.

GitHub Repository

1. Why I Built This

Standard LLM completions lack stateful memory, multi-step reasoning, and deterministic tool execution. SupportFlow AI demonstrates an enterprise agentic workflow orchestrating local language models via Ollama and LangGraph for zero-data-leakage enterprise automation.

2. LangGraph Stateful Graph Architecture

The platform uses LangGraph state graphs to represent conversational state, agent memory nodes, RAG retrieval branches, and dynamic tool calling. A central query router determines whether to query persistent vector memory or dispatch specialized agent tools.

3. Categorized Technology Stack

Frameworks: LangGraph, LangChain
LLM Engine: Ollama Local LLMs, OpenRouter API
Agent Capabilities: Persistent Memory, Tool Calling, Vector RAG
Language: Python

4. Engineering Challenges & Trade-offs

Running local LLMs via Ollama introduces memory and latency constraints. By implementing streaming response buffers and prompt compaction algorithms, SupportFlow AI delivers responsive agentic execution entirely on local infrastructure.
