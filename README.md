# 📖 Overview

This repository contains my personal engineering portfolio built to showcase my projects, technical skills, engineering journey, and interests in Artificial Intelligence, Cybersecurity, and Full-Stack Development.

The portfolio is designed with a modern editorial-inspired interface, interactive project case studies, and recruiter-friendly navigation to provide a clean and engaging experience.

- Modern editorial UI inspired by premium product websites
- Fully responsive across desktop, tablet, and mobile devices
- Interactive project case studies

# 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/Pranay-Kumar-02/pranay-portfolio.git
```

Go to the project folder:

```bash
cd pranay-portfolio
```

Open `index.html` in your browser.

Or run a local server using VS Code Live Server.
